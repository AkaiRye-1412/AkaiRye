# 售后工作台 · 交互原型

依据《项目需求文档.md》（v1.1，2026-11-25）制作的纯前端可交互原型，用于验证页面结构、信息层级与关键交互流程。

> 只做交互设计，不含后台逻辑。所有数据为本地模拟数据，不会读写真实 Obsidian vault、PDF、Git 仓库或终端。

## 打开方式

- 直接双击 `index.html`（推荐 Chrome / Edge），或用本地静态服务：
  ```bash
  cd prototype
  python -m http.server 8765
  # 浏览器访问 http://127.0.0.1:8765/
  ```
- 页面状态（会话、笔记草稿、配置、终端标签等）保存在浏览器 `localStorage`；可在「设置 → 原型数据 → 重置数据」恢复初始状态。

## 页面与交互覆盖

| 区域 | 可体验的交互 |
|---|---|
| 首页台面 | 进行中 / 已归档切换、按客户分组折叠、待跟进提醒、看板数据范围切换、代码仓库折叠区 |
| 所有笔记 | 按 vault 原目录树折叠浏览、关键词搜索（标题+正文高亮）、三态勾选纳入/移出知识库、全部/已勾选/未勾选筛选、点击只读阅读、概览统计与当前来源 chips、未纳入笔记仍可阅读 |
| 笔记编辑器 | 头部字段编辑、Markdown 编辑 / 分栏 / 预览、自动保存、8 秒索引倒计时、新建笔记模板、归档 / 取消归档 |
| 文件冲突 | 笔记右上角「⋯ → 模拟外部修改冲突」演示重新加载 / 覆盖 / 另存副本 |
| 知识助手 | 6 种检索范围（含自动感知当前笔记）、回答与来源角标、来源展开与跳转、命中片段、跨品牌对比、会话新建 / 重命名 / 删除 / 清空 |
| 无依据回答 | 在「当前项目」范围提问 E-07 等范围外问题，会明确提示「未找到」，不编造 |
| 内置 PDF 阅读器 | 从来源角标或知识库打开、页码跳转、命中高亮、多标签、并排对比 |
| 知识库 | 选择 PDF 入库、后台队列与进度、解析中 / 失败 / 有更新 / 路径失效状态、重试、重建、重新定位、删除清理、笔记索引重建 |
| PDF手册 | 浏览配置的本地 PDF 根目录、按文件夹分组折叠、搜索 / 品牌 / 状态筛选、点击文件在页面右侧内嵌预览、预览内翻页与全屏模式、未入库文件一键加入知识库、失效引用提示、重新扫描 |
| 终端 | 多标签、独立工作目录、真实感的模拟输出、`/` 内置命令、运行中标签关闭二次确认、会话本地持久化 |
| 代码仓库 | 置顶 / 隐藏、刷新状态、只读展示、在仓库目录打开终端 |
| 存量整理 | 扫描 → 预览（可改字段 / 跳过）→ 写入 → 一键回滚，全部为本地演示 |
| 设置 | LLM / Embedding 配置、路径与白名单、品牌枚举、待跟进阈值、自动备份、快捷键、隐私边界、原型数据重置 |

## 默认快捷键

| 操作 | 快捷键 |
|---|---|
| 全局提问 / 定位顶部输入框 | `Ctrl + K` |
| 新建售后笔记 | `Ctrl + N` |
| 打开终端 | `Ctrl + \`` |
| 知识助手发送 | `Enter` 或 `Ctrl + Enter`（`Shift + Enter` 换行） |
| 保存当前笔记 | `Ctrl + S` |
| 关闭弹窗 / 阅读器 | `Esc` |

## 演示数据说明

- 演示时间基准固定为 **2026-11-25**；客户、项目、手册、会话、仓库均为构造数据。
- 手册解析 / 入库队列在页面打开后会真实推进进度（模拟），约每 1.6 秒刷新一次。
- 「模拟外部修改冲突」「在 Obsidian 中打开」「测试连接」等按钮只展示交互反馈，不触发真实外部操作。
- 知识库的「重建 / 忽略 / 稍后」、笔记索引倒计时、会话删除确认等均可在界面上完整走通。

## 目录结构

```
prototype/
├─ index.html
├─ css/
│  ├─ base.css      基础变量、布局、通用组件
│  ├─ pages.css     首页 / 笔记 / 编辑器 / 知识库
│  ├─ views.css     终端 / 仓库 / 设置 / 整理 / 阅读器
│  ├─ pdf.css       PDF手册页面
│  └─ rag.css       右侧知识助手与对比表
└─ js/
   ├─ icons.js      内联图标
   ├─ data.js       模拟数据
   ├─ ui.js         通用工具、弹窗、菜单、Markdown 预览
   ├─ charts.js     看板趋势与客户分布
   ├─ views-*.js    各页面视图（含 views-pdf.js：PDF手册）
   ├─ reader.js     内置 PDF 阅读器（支持本地未入库预览）
   ├─ rag-engine.js 检索范围与模拟回答
   ├─ rag.js        知识助手面板
   └─ app.js        路由、快捷键、新建笔记、后台队列模拟
```

## 原型边界

- 不包含真实文件读写、Obsidian 监听、MinerU / 云端模型调用、真实 PTY、Git 读取与打包部署；
- 未实现多用户、登录、局域网访问；
- 所有「来源跳转」仅在本原型内打开模拟页面，不会打开真实 PDF 文件。
